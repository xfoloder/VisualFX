# VisualFX 1.19.7 — Minecraft 1.21.11 / Fabric

## Палитра меню и координаты

В **Misc → Меню** выберите палитру всего интерфейса. В редакторе доступны свой оттенок и градиент. В **Misc → Watermark** можно отдельно включить или скрыть FPS, пинг и координаты блока (XYZ). Панель подстраивается под выбранные строки.

## Color Hit и меню Watermark

- **Combat → Color Hit** включает окрашивание модели игрока при вашем ударе. Цвет затухает вместе со штатной анимацией получения урона.
- Откройте «Редактор цветов» и выберите оттенок на радужной полосе. В квадрате по горизонтали меняется насыщенность, по вертикали — яркость. Нижняя полоса также меняет яркость. Доступны HEX и две точки градиента. Нажмите «Применить», чтобы сохранить выбор.
- **Right Shift** раскрывает меню из Watermark и сворачивает его обратно. Положение и масштаб Watermark задаются в **Misc → Watermark**.


При первом запуске VisualFX добавляет **Cynthia-metaphor** (`cynthia-metaphor.gomc.me`) в сохранённый список серверов, если такого адреса там ещё нет. При первом открытии списка за запуск появляется плашка с приглашением. Добавленную запись можно удалить обычной кнопкой в списке серверов.

Перенос последней версии со всеми функциями: 13 режимов Target ESP, TargetHUD с привязкой к игроку, Death Effect (Ascend / Exit Hell), Hit Effect, Watermark, оптимизация и управление SoundCloud.

## Item Physics, Item Scroller и сезонные частицы

- **Visual → Item Physics**. Выпавшие предметы кувыркаются в воздухе и перестают вращаться на земле. Настройка меняет только отображение.
- **Misc → Item Scroller**. Удерживайте Shift и прокрутите колесо над стопкой, чтобы перенести её штатным быстрым перемещением. Работает в обычных контейнерах.
- **Visual → Частицы**. Выберите снежинки или осенние листья и настройте плотность. Частицы видны под открытым небом.

## Зелёная кошка и статусы друзей

**Misc → Связь** подключает общую комнату. У участников на одном сервере появляется зелёная кошка в списке Tab и на видимых никах над игроками. Когда участник открывает VisualFX, рядом показывается название вкладки или действие, например «Редактор цветов» или «Меняет параметр». «Показывать меню» управляет отправкой этого статуса. Подключение по умолчанию выключено.

1. Один из игроков запускает отдельный ретранслятор. Для локальной проверки достаточно команды `java -jar visualfx-presence-relay.jar`. Для игры в одной локальной сети запустите `java -jar visualfx-presence-relay.jar 0.0.0.0 27640` и используйте локальный IP компьютера, запустившего его. Ретранслятор запускается на Java 21 или новее.
2. В **Misc → Связь → Настроить комнату** укажите адрес, например `http://192.168.1.10:27640`. Создайте ключ кнопкой «Создать ключ» и передайте его друзьям приватно. Для подключения через интернет ретранслятор должен быть доступен друзьям по HTTPS, например через обратный прокси.
3. Все участники один раз вводят один адрес ретранслятора и один ключ комнаты, нажимают «Сохранить и включить» и заходят на один сервер Minecraft по одинаковому адресу. При каждом входе VisualFX сам подключается к сохранённой комнате. В **Misc → Связь** можно выключить автоподключение или отдельно скрыть статус меню. Ретранслятор запускается отдельно, мод или плагин на сервер Minecraft ставить не требуется.

Клиент отправляет псевдоним, вычисленный из UUID и ключа, и состояние из фиксированного списка. Введённые строки, значения настроек, координаты и содержимое инвентаря остаются в клиенте. Ретранслятор держит активность в памяти около девяти секунд после последнего обновления. Кошка служит отметкой участника комнаты, которой вы доверяете.

## Установка

1. Minecraft Java Edition строго 1.21.11, Fabric Loader 0.18.4 или новее, Java 21.
2. Удалите предыдущий JAR VisualFX из папки mods данного профиля.
3. Поместите visualfx-1.19.7-mc1.21.11.jar и Fabric API 0.141.3+1.21.11 в mods.
4. Запустите профиль Fabric. Установка на сервер не требуется.

Fabric Installer: https://fabricmc.net/use/installer/
Fabric API: https://modrinth.com/mod/fabric-api/versions?g=1.21.11
Сборки VisualFX для 26.3 не подходят для 1.21.11.

## Меню и функции

Right Shift открывает и закрывает меню. В верхнем ряду выберите категорию, во втором — функцию. Настройки меняются мышью и сохраняются автоматически в config/visualfx.json. В длинных списках работает прокрутка колесом.

| Категория | Вкладка | Настройки |
| --- | --- | --- |
| Visual | Target ESP | Включение, 13 режимов, палитра/перелив, скорость, радиус, свечение, осколки, плавность |
| Visual | TargetHUD | Включение, отдельная палитра, масштаб 50–200%, смещение от цели |
| Visual | Death Effect | Включение, Ascend / Exit Hell |
| Combat | Hit Effect | Шесть режимов, сила, длительность и предпросмотр |
| Misc | Watermark | FPS, пинг, палитра, масштаб и расположение |
| Misc | Оптимизация | Облегчённая геометрия VisualFX, пресеты Minecraft, применение и восстановление |
| Misc | SoundCloud | Открытие плеера, громкость, отключение связи с браузером |
| Misc | Меню | Непрозрачность, анимации, сброс настроек |

Target ESP выделяет только игрока под прицелом, с коротким затуханием прежней цели. Режимы: Орбитальный разлом, Двойная спираль, Цифровой сбой, Руническая орбита, Энергоклетка, Неоновая корона, Вихрь осколков. Свечение создаётся оболочками геометрии, без экранного bloom.

TargetHUD следует над головой выбранного игрока. «Смещение от цели» открывает редактор с условной головой: перетащите панель мышью, колесом измените масштаб. «Готово», Escape или Right Shift возвращают в меню. За камерой и за пределами кадра панель скрывается. Здоровье отображается по данным клиента.

Death Effect срабатывает один раз при получении состояния смерти последнего выбранного игрока. После потери прицела он отслеживается ещё до двух секунд. Эффект длится 52 тика, одновременно — до четырёх вспышек. Выход или выгрузка игрока не считаются смертью. Функция не требует, чтобы именно вы нанесли последний удар. Ascend использует палитру, Exit Hell — огненный оранжево-красный цвет. Общие радиус, свечение и количество осколков задаются в Target ESP.

Hit Effect отражает локальную попытку атаки; подтверждение урона сервером не запрашивается. Watermark остаётся закреплённым на экране и перемещается через собственный редактор.

## Оптимизация

«Лёгкие эффекты» уменьшает количество сегментов, оболочек свечения и осколков VisualFX. «Применить к игре» явно меняет штатные параметры Minecraft и сохраняет исходные значения в optimizationBackup в config/visualfx.json. «Вернуть настройки» восстанавливает эту копию и отключает лёгкие эффекты. Общий сброс мода сохраняет копию для восстановления.

| Профиль | Дальность, не более | Симуляция, не более | Дальность сущностей | Частицы | Облака | Мягкое освещение | Осколки, не более |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Баланс | 12 чанков | 8 чанков | До 75% | Уменьшено | Выкл. | Сохраняется | 24 |
| Больше FPS | 8 чанков | 5 чанков | До 50% | Минимум | Выкл. | Выкл. | 12 |
| Минимум нагрузки | 5 чанков | 5 чанков | До 50% | Минимум | Выкл. | Выкл. | 6 |

Пресеты не увеличивают уже более низкую дальность/количество частиц. Симуляцию на внешнем сервере определяет сервер. Реальный прирост FPS не измерен. При восстановлении заменяются и ручные изменения этих параметров, сделанные после применения пресета.

## SoundCloud

1. Misc → SoundCloud → «Плеер SoundCloud» → «Открыть».
2. Вставьте полную HTTPS-ссылку https://soundcloud.com/author/track или https://soundcloud.com/author/sets/playlist.
3. Нажмите «Открыть браузер» и при необходимости один раз Play в официальном виджете.
4. Оставьте вкладку открытой и вернитесь в Minecraft. Доступны Play/Pause, Stop, переключение треков плейлиста, громкость и перемотка нажатием/перетаскиванием полосы.

Звук воспроизводится в браузере, управление — в игре, API-ключи не требуются. Если браузер не открылся автоматически, нажмите «Копировать ссылку», откройте локальный адрес вручную и загрузите трек из игры. Обычное закрытие экрана плеера не останавливает музыку. «Отключить» или завершение Minecraft разрывают связь; страница ставит виджет на паузу после обнаружения разрыва. Доступность треков и плейлистов определяется SoundCloud. Короткие ссылки сначала откройте в браузере и скопируйте полный адрес. При приостановке фоновой вкладки вернитесь в браузер.

Локальный сервер запускается по кнопке, слушает только 127.0.0.1, использует случайный порт и адрес сессии, проверяет Origin/Host. Музыку мод не скачивает и не декодирует. Последняя ссылка и громкость сохраняются; автоматического открытия браузера или воспроизведения при запуске игры нет.
Документация виджета: https://developers.soundcloud.com/docs/api/html5-widget

## Сборка

Требуются JDK 21 и интернет при первой сборке.
Windows: gradlew.bat build
Linux/macOS: chmod +x gradlew && ./gradlew build
Установочный файл: build/libs/visualfx-1.19.3+1.21.11.jar (без суффикса -sources).

Зафиксированы Minecraft 1.21.11, официальные Mojang Mappings через Loom, Loader 0.18.4, Fabric API 0.141.3+1.21.11, Loom 1.14.10, Gradle 9.2.1. Клиентские миксины подключают TargetHUD, рендер выпавших предметов, обработку прокрутки и отметки участников комнаты.

Результаты фактической проверки и ограничения — в VERIFICATION.md.

## Обновление до 1.18.1

- **Visual → Effect Status** показывает активные эффекты, уровни и таймеры. Размер задаётся ползунком 50–200%. Положение меняется перетаскиванием образца в редакторе, там же масштаб меняется колесом.
- **Misc → Watermark** показывает FPS и серверный пинг. В одиночной игре выводится прочерк вместо пинга.
- **Visual → Neon Echo** рисует след движущегося игрока под прицелом и световой импульс при ударе. Длину записи, число силуэтов и цвет можно настроить.
- **Редактор цветов** поддерживает RGB, HEX и двухцветный градиент для Target ESP, TargetHUD, Watermark и Neon Echo.
- Основное меню перемещается мышью за заголовок. Масштаб настраивается в Misc → Меню.
- В Target ESP также доступны звёздная клетка, радар, неоновый лотос, орбитальные кометы, квантовые кубы и грозовой контур. В Combat → Hit Effect есть ударная волна, крестовой разрез, кристальный взрыв, электроразряд, плазменная сфера и руническая печать.

## Сравнение Java и Rust — 1.19.0

В Misc → Оптимизация → «Расчёт геометрии» переключаются Java и Rust. Java выбрана по умолчанию. Rust доступен на Windows x64. Библиотека встроена в JAR, поэтому для установки и запуска Rust отдельно ставить ничего не нужно. Если библиотека недоступна, используется Java.

Rust формирует вершины лент и свечения для визуальных эффектов мода. Java по-прежнему вычисляет форму эффектов и отправляет вершины в игровой рендерер. Настройки Minecraft переключатель не меняет.

Для сравнения FPS включите Watermark и оставьте одни и те же настройки. Наведите прицел на другого игрока с включённым Target ESP. Посмотрите на FPS в течение примерно 30 секунд в режиме Java, затем повторите с Rust в той же сцене. При включённой вертикальной синхронизации или низком лимите FPS разница может быть скрыта.

При сборке из архива Gradle использует включённую библиотеку. Чтобы пересобрать её из Rust-кода, установите Rust для Windows x64 MSVC и запустите `native/build.ps1`, затем повторите `gradlew.bat assemble`.

[Спецификация JNI для Java 21](https://docs.oracle.com/en/java/javase/21/docs/specs/jni/design.html) · [Целевые платформы Rust для Windows MSVC](https://doc.rust-lang.org/rustc/platform-support/windows-msvc.html)
