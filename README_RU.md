# VisualFX 1.6.0+26.3 — Minecraft 26.3 / Fabric

Клиентские неоновые эффекты выбранного прицелом игрока и терминальное меню.

## Установка

1. Установите Minecraft Java Edition **26.3** и Fabric Loader **0.20.1 или новее**.
2. Установите Java 25, если ваш лаунчер не предоставляет её автоматически.
3. Скопируйте `visualfx-1.6.0+26.3.jar` и Fabric API **0.166.2+26.3** в папку `mods` игрового профиля.
4. Запустите профиль Fabric. Серверная установка не требуется.

Fabric API: https://modrinth.com/mod/fabric-api/versions?g=26.3
Fabric Installer: https://fabricmc.net/use/installer/

## Управление

**Правый Shift** открывает и закрывает меню. Escape также закрывает его с анимацией.
Вверху меню находятся вкладки Combat, Misc и Visual. Нажимайте строки переключателей и выбора режимов.
Остальные параметры меняются нажатием и перетаскиванием полосы справа.
Color palette предлагает четыре заданных неоновых цвета и плавный циклический градиент.
Все изменения автоматически сохраняются в `config/visualfx.json`.
SMOOTHING задаёт время появления и исчезновения: большее значение — более медленный переход.

Наведите прицел на другого живого игрока в пределах обычного клиентского наведения.
Эффект не ищет игроков за стенами и не увеличивает дальность выбора цели.
При переводе прицела предыдущий эффект затухает, новый появляется; одновременно используются максимум два слота перехода.
При открытии меню цель теряется и эффект плавно исчезает.
Реакция на удар показывает локальную попытку атаки: сервер может отклонить её, поскольку мод не получает подтверждение урона от сервера.

## Режимы

- Orbital Rift: два наклонённых кольца, орбитальные осколки, пульсация.
- DNA Helix: две вращающиеся спирали с поперечными связями.
- Digital Glitch: ступенчатые вспышки и геометрические разрывы.
- Runic Orbit: собственные геометрические руны, орбиты и звёздный узор.

Геометрия использует штатные буферы рендеринга Fabric, без обычных частиц и прямых вызовов устаревшего OpenGL. Свечение имитируется полупрозрачными оболочками геометрии; это не экранный bloom. Проверка глубины сохраняется.
Используется стандартный шрифт Minecraft с поддержкой русского языка.

## Сборка

Требуется JDK 25 и интернет при первой сборке.

Windows: `gradlew.bat build`
Linux/macOS: `chmod +x gradlew && ./gradlew build`

Установочный файл: `build/libs/visualfx-1.6.0+26.3.jar`.
Файл с суффиксом `-sources.jar` предназначен для разработки, его не нужно класть в mods.

Зависимости зафиксированы: Minecraft 26.3, официальные имена классов Minecraft (без Yarn), Loader 0.20.1, Fabric API 0.166.2+26.3, Loom 1.17.21, Gradle 9.6.0.
Дополнительные библиотеки кроме Fabric API не требуются; Gson поставляется Minecraft.

## Категории меню 1.2.0

- Combat: Target ESP, Hit Effect, Hit intensity (сила визуальной вспышки и осколков).
- Misc: Menu opacity, Menu animations, Reset settings. Сброс всех параметров требует второго клика в течение трёх секунд.
- Visual: ESP mode, Color palette, Rotation speed, Ring size, Glow intensity, Shard count, Smoothing.

Ползунки работают нажатием или перетаскиванием мышью. Изменения сохраняются при отпускании ползунка, переключении вкладок и закрытии меню. Обычные переключатели сохраняются сразу. Старый config/visualfx.json совместим; новые поля получают значения по умолчанию. Последняя вкладка запоминается в пределах текущего запуска игры.

## Обновление 1.3.0

Русские подписи, значения и подсказки; разделы Combat / Misc / Visual сохранены. Длинные подписи сокращаются многоточием, полное значение видно при наведении.
В меню появился анимированный предпросмотр выбранного эффекта вокруг силуэта игрока. Он использует геометрию игровых эффектов и реагирует на цвет, скорость, размер, свечение и количество осколков.
Если ширина интерфейса не меньше 400 GUI-пикселей, предпросмотр находится справа. В очень узком окне он отображается под настройками Combat и Misc; для одновременного просмотра настроек Visual и предпросмотра уменьшите масштаб интерфейса в настройках Minecraft.
Предпросмотр является проекцией геометрии на плоскость меню, а не снимком игрока в мире.

## Новые эффекты 1.4.0

Вкладка Visual → Вид эффекта теперь переключает семь режимов.

- Энергоклетка: вращающаяся объёмная сетка вокруг цели и кольцо, сканирующее её снизу вверх.
- Неоновая корона: парящая корона с зубцами разной высоты и орбитальными осколками.
- Вихрь осколков: поднимающиеся по спирали осколки с изогнутыми световыми следами.

Цвет, скорость, размер и свечение действуют на новые режимы; число осколков регулирует корону и вихрь. Энергоклетка использует фиксированную ограниченную сетку. Новые режимы видны в предпросмотре. Первые четыре значения режима в старом конфигурационном файле сохранены.

## Death Effect — версия 1.5.0

Right Shift → Visual → Death Effect включает визуальную реакцию на смерть цели. Строка «Эффект смерти» переключает два варианта:

- Ascend — три световых ореола поднимаются вверх вместе с потоком осколков. Использует выбранную неоновую палитру.
- Exit Hell — оранжево-красный разлом на земле с расходящимися трещинами, энергетическими рёбрами и поднимающимися искрами.

При наведении мыши на эти две настройки или их переключении панель предпросмотра показывает эффект смерти. Для возврата к предпросмотру обычного эффекта нажмите другую настройку. Остальные параметры Visual доступны прокруткой колеса мыши над списком слева.

Функция работает независимо от переключателя Target ESP. Отслеживается последний живой игрок под прицелом, кроме вас; после потери наведения наблюдение сохраняется до двух секунд. Когда клиент получает состояние смерти этой цели, запускается один эффект на месте смерти длительностью 52 тика (примерно 2,6 секунды). Исчезновение, выгрузка или выход игрока не считаются смертью. Это не проверка того, кто нанёс последний удар: эффект появляется и если выбранного игрока убил кто-то другой.

Одновременно хранится не более четырёх эффектов смерти; при переполнении заменяется самый старый. При смене мира, отключении от сервера и выключении Death Effect они очищаются. Размер, свечение и количество осколков берутся из настроек Visual. Death Effect имеет собственную длительность и не зависит от скорости вращения Target ESP. Выбранный режим и переключатель автоматически сохраняются в config/visualfx.json.

## TargetHUD и палитра — версия 1.6.0

Right Shift → Visual → TargetHUD включает отдельную панель с именем игрока и полосой здоровья. Она появляется справа ниже прицела при наведении на живого игрока и плавно исчезает после потери цели. Панель не зависит от включения Target ESP.

В строке «Палитра TargetHUD» нажимайте цветные образцы: зелёный, розовый, голубой, фиолетовый или анимированный перелив. Белая рамка отмечает выбранный вариант. Нажатие на подпись строки также переключает цвета по порядку. Палитра HUD сохраняется отдельно от палитры ESP в config/visualfx.json (hudPalette); переключатель — targetHud.

Цвет меняет рамку панели и полосу здоровья. При наведении на настройки TargetHUD справа в меню отображается пример с именем «Игрок» и 16 из 20 HP. В игре используются имя и здоровье цели, известные клиенту; серверные механики с отдельным представлением здоровья могут отличаться от этих значений. Панель скрывается при открытом меню и вместе со штатным HUD при F1.
