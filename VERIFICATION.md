# Проверка VisualFX 1.7.0 — Minecraft 26.3

Изменена организация меню: категории Combat / Misc / Visual и отдельный второй ряд вкладок Target ESP, TargetHUD, Death Effect, Hit Effect, Меню. Параметры распределены по соответствующим функциям; числовые поля и формат конфигурации сохранены.
Предпросмотр зависит от вкладки. При смене вкладки сбрасываются перетаскивание, подтверждение сброса и прокрутка. Число видимых строк адаптируется к высоте окна; прокрутка ограничена длиной текущего списка.
Проверка: Gradle build на JDK 25, Gradle 9.6.0, Loom 1.17.21. Автоматических игровых тестов нет (test NO-SOURCE). Версия 1.7.0 не запускалась в игре; расположение элементов и клики визуально не проверены.
