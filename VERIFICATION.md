# Проверка VisualFX 1.11.0 — Minecraft 26.3

- Gradle build успешен на JDK 25, Gradle 9.6.0, Loom 1.17.21.
- Выполнен runClient: VisualFX 1.11.0+26.3 загружен Fabric; клиент инициализировал SDL/OpenGL, звук и ресурсы. Браузер автоматически не запускался. Realms сообщил об автономном профиле Fabric; это не ошибка плеера.
- Изолированные проверки реального SoundCloudPlayer прошли: допустимые/недопустимые ссылки, HTML-ресурс, запрет чужого Origin и неверной сессии, порядок команд, синхронизация статуса, ограничение очереди 64 командами и выключение сервера. Проверки используют минимальные заглушки Config/VisualFX, чтобы запускать код вне игры; исходники в verification/bridge.
- JavaScript страницы прошёл синтаксическую проверку и проверку отправки команд на имитации официального виджета: load, volume, seek, toggle, next, prev, stop, получение метаданных.
- Gradle test сообщает NO-SOURCE: перечисленные изолированные проверки запускались отдельно.
- Настоящий браузерный виджет, воспроизведение звука SoundCloud, первый пользовательский Play, управление из запущенной игры и работа плейлистов фактически не проверены. Имитация виджета и запуск клиента не заменяют эти проверки.

Реализация без API-ключей: интерфейс управления в Minecraft, звук через официальный виджет в открытой вкладке браузера. Внутри Minecraft аудиодекодер SoundCloud не запускается.
