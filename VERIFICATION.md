# Проверка VisualFX 1.6.0 — Minecraft 26.3

Сборка Gradle build успешна: JDK 25, Gradle 9.6.0, Loom 1.17.21.
Новый TargetHud подключён через HudElementRegistry перед CHAT. Код компилируется против Fabric API 0.166.2+26.3 и Minecraft 26.3.
В конфигурации добавлены отдельные targetHud / hudPalette. Кнопки палитры, предпросмотр, плавное появление и полоса здоровья скомпилированы.
Автоматических игровых тестов нет (test NO-SOURCE). Версия 1.6.0 не запускалась в игре; визуальный вид, выбор цвета мышью, показ здоровья на сервере и Sodium фактически не проверены.
