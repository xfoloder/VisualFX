# Проверка VisualFX 1.16.0 — Minecraft 26.3

Добавлены EchoHistory, EchoVisual, NeonEcho, собственный цветовой профиль и вкладка Visual → Neon Echo. Ввод и механика игры не изменены.

- Gradle build успешен на JDK 25, Gradle 9.6.0, Loom 1.17.21.
- Тест реального EchoHistory прошёл: 32 точки, истечение срока жизни, независимость снимка, смена цели, сброс при телепортации, подавление неподвижных записей, поворот и очистка.
- Изолированная проверка реального EchoVisual/Geometry с минимальными заглушками прошла: 1344 сочетания параметров на демонстрационной истории; координаты конечны и ограничены, бюджет <=4000 вершин, состояние Geometry восстанавливается.
- Проверка профилей ColorStyle/ColorTarget с заглушкой Config прошла, включая независимое применение цвета Neon Echo.
- Настоящий клиент запущен с отдельным временным проверочным модом: открылось главное меню на вкладке Neon Echo, предпросмотр отрисовывался 80 клиентских тиков без вылета, журнал содержит ECHO_UI_PASS, клиент завершён штатно. Это проверка отрисовки кода предпросмотра, а не субъективная визуальная оценка. Проверочный мод не входит в установочный JAR.
- Gradle test сообщает NO-SOURCE: перечисленные тесты запускались отдельно. Исходники в verification/echo, verification/geometry, verification/colors, verification/ui-smoke.
- След движущегося игрока в мире, импульс реальной атаки, очистка при игровом телепорте, взаимодействие с Sodium и FPS в игровой сцене фактически не проверены.
