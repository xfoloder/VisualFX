# VisualFX — проверки в Minecraft 26.3

## 1.19.6

В одиночном мире Fabric проверены три независимых переключателя Watermark, все восемь сочетаний, сохранение настроек, значения по умолчанию для старых конфигураций и высота панели в каждом состоянии.

## 1.19.5

Gradle собрал установочный JAR. В локальном мире Fabric проверены выбор пресета во вкладке меню, предпросмотр пользовательского оттенка, сохранение темы и независимость палитры Watermark. Проверены координаты игрока с отрицательными значениями, форматирование координат у границы мира и высота Watermark с новой строкой.

## 1.19.4

Gradle собрал установочный JAR. В одиночном мире Fabric автоматическая проверка подала событие урона от локального игрока тестовой модели. Проверены выбранный цвет и отключение красного оверлея, затухание, возврат обычного цвета, урон из другого источника и выключенный Color Hit. Проверены выбор зелёного оттенка на цветовой полосе и открытие и закрытие меню из перемещённого Watermark. Проверка использовала тестовые события в клиенте.

## 1.19.3

Сборка Gradle прошла. В изолированном клиенте проверены добавление Cynthia-metaphor в пустой список, плашка при открытии списка, отсутствие повторной плашки за запуск, распознавание адреса с другим регистром и портом 25565, сохранность других записей и возможность удалить добавленный сервер.

## 1.19.1

Сборка Gradle прошла на Java 25. В одиночном мире с Fabric и Sodium 0.9.3-beta.5 проверены запуск клиента, рендер выпавшего предмета и обоих типов частиц, загрузка инвентаря, четыре новые вкладки и окно настройки ретранслятора. Зелёная кошка и подпись активности отображались с тестовым статусом. Локальный HTTP-тест ретранслятора проверил обмен статусом между двумя участниками, изоляцию комнат, отказ запросу без ключа и истечение статуса после отключения.

Сетевой запуск на двух игровых компьютерах и перенос стопки с физически зажатым Shift в этой проверке не выполнялись.

## 1.19.0

Сборка Gradle assemble прошла. В клиенте Fabric 26.3 с Java 25 загрузилась библиотека Rust. Число, порядок, координаты и цвета вершин совпали в 416 случаях Target ESP и в серии из 1200 линий, пересекающей границу пакета.

Медиана расчёта «Энергоклетки» составила 131,9 мкс на Java и 152,3 мкс на Rust. Замер включает передачу данных между Java и Rust. Игровой FPS и отрисовка мира в замер не входили. Java выбрана по умолчанию.
