# Проверка VisualFX 1.15.1 — Minecraft 26.3

Причина из найденного crash-report: NullPointerException в SoundCloudScreen при status.paused(). Статическое поле INSTANCE конструировалось раньше EMPTY, поэтому status впервые получал null. EMPTY перенесён выше INSTANCE; маскировка исключения в отрисовке не используется.

- Регрессионный тест начального status до запуска сервера: старый SoundCloudPlayer падает с AssertionError, исправленный проходит. Также повторно прошли проверки URL, HTML, Origin/сессии, команд, статуса, очереди и shutdown. Тест использует реальные SoundCloudPlayer и минимальные заглушки Config/VisualFX.
- В настоящем клиенте Minecraft 26.3 запущен отдельный временный dev-мод проверки экрана: первое открытие SoundCloudScreen и повторное открытие по 80 тиков без браузера/трека. Оба открытия и отрисовка прошли, журнал содержит UI_SMOKE_PASS, клиент завершился штатно.
- Проверочный мод хранится отдельно и не включён в установочный JAR. Исходник: verification/ui-smoke. Физическое нажатие кнопки мышью не автоматизировалось: проверялось создание того же экрана, которое выполняет обработчик кнопки.
- Gradle build успешен на JDK 25 / Gradle 9.6.0 / Loom 1.17.21. Сборка для Minecraft 26.3, Fabric API 0.166.2+26.3, Loader 0.20.1.
- Реальное браузерное воспроизведение SoundCloud не проверялось; этот фикс относится к вылету при открытии экрана.
