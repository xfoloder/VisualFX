# Проверка VisualFX 1.3.0 для Minecraft 26.3

17 ноября 2026: проект собран Gradle 9.6.0 на JDK 25. Использованы Loom 1.17.21, Fabric Loader 0.20.1 и Fabric API 0.166.2+26.3.
Русские строки сохранены в UTF-8; JavaCompile использует UTF-8. Новый класс EffectPreview рисует проекцию геометрии из общих реализаций Effects.
Автоматических игровых тестов нет (test NO-SOURCE). Для версии 1.3.0 запуск и визуальная проверка меню не выполнялись; эффекты на втором игроке и Sodium не проверены.
