# Проверка VisualFX 1.15.0 — Minecraft 26.3

- Gradle build прошёл на JDK 25, Gradle 9.6.0, Loom 1.17.21. Собраны редактор, профили и подключение пользовательских палитр к эффектам, HUD и Watermark.
- Выполнен runClient: Fabric загрузил VisualFX 1.15.0+26.3; клиент инициализировал SDL/OpenGL, звук и ресурсы. Ошибок загрузки VisualFX не обнаружено. Предупреждение Realms относится к автономному профилю Fabric.
- Изолированные проверки реальных ColorStyle и ColorTarget прошли: допустимый/недопустимый HEX, формат RGB, границы смешивания, 1407 выборок палитр, цикл градиента, нормализация некорректных значений, JSON round trip, независимость трёх целей, копирование черновика. Использована минимальная заглушка Config; исходники в verification/colors.
- Gradle test сообщает NO-SOURCE; проверки цветов запускались отдельно.
- Ползунки RGB, ввод HEX, кнопки «Применить»/«Отмена», градиенты в игровой сцене и Sodium фактически через интерфейс не проверены. Запуск клиента и тестирование модели цвета не заменяют визуальную проверку редактора.
- Ветка 1.21.11 не обновлялась. Эта сборка предназначена для 26.3.
