# VisualFX 1.19.0 — Minecraft 1.21.11

Сборка для Fabric прошла. В запущенном клиенте на Java 21 нативная библиотека загрузилась. Совпали число, порядок, координаты и цвета вершин в 416 случаях Target ESP и отдельной серии из 1200 линий, которая пересекает границу пакета.

В изолированном замере расчёта эффекта «Энергоклетка» медиана составила 137,4 мкс на Java и 143,8 мкс на Rust. Замер включает передачу данных между Java и Rust. Рендеринг мира и FPS в замер не входили. На другом компьютере результат может отличаться. Java оставлена режимом по умолчанию.
