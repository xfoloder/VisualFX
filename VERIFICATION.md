# Проверка VisualFX 1.9.0 — Minecraft 26.3

Gradle build успешен на JDK 25, Gradle 9.6.0, Loom 1.17.21, с Fabric API 0.166.2+26.3.
TargetHUD получает проекцию интерполированной позиции игрока над головой через CameraRenderState.viewRotationMatrix / projectionMatrix в END_EXTRACTION. В HUD передаётся снимок координат, без сохранения объекта игрока. Точки за камерой и вне кадра отбрасываются; границы карточки ограничены размером окна.
HudPlacement и редактор используют одинаковое смещение относительно условной головы цели; Watermark сохраняет экранное позиционирование. Добавлены hudOffsetX / hudOffsetY.
Автоматических игровых тестов нет (test NO-SOURCE). Версия 1.9.0 в игре не запускалась: следование за движущимся игроком, проекция при разных FOV, редактор и Sodium визуально не проверены.
