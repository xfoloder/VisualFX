# VisualFX 1.18.1 — Minecraft 1.21.11

Сборка Gradle assemble и remapJar прошли на Java 21. Клиент Fabric 1.21.11 загрузил VisualFX и игровые ресурсы без ошибок загрузки мода. Проверены наличие Effect Status и Neon Echo в JAR и преобразование метода FOV в intermediary для TargetHUD. Отрисовку в мире, взаимодействие с меню и серверный пинг в этой версии не проверяли.
