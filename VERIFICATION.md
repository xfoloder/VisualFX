# Проверка VisualFX 1.12.0 — Minecraft 1.21.11

- Выполнена сборка Gradle build на JDK 21, Gradle 9.2.1, Loom 1.14.10. Выполнен remapJar для установки в обычный профиль Fabric, а не только запуска в dev-среде.
- Выполнен runClient с Minecraft 1.21.11, Fabric Loader 0.18.4, Fabric API 0.141.3+1.21.11: VisualFX загружен, инициализировались LWJGL/OpenGL, звук и игровые ресурсы. Ошибок загрузки нового Mixin Invoker в журнале нет. Сообщение об авторизации Realms относится к автономному профилю Fabric.
- В установочном JAR проверено преобразование Invoker getFov в intermediary method_3196. Рефмап не требуется: используется стандартное преобразование Loom.
- Изолированные проверки SoundCloudPlayer на Java 21 прошли: проверка ссылок, HTML-ресурс, Origin и случайный адрес сессии, порядок команд, статус, ограниченная очередь и закрытие соединения. Исходники проверки — verification/bridge; используются минимальные заглушки Config/VisualFX вне Minecraft.
- Код всех последних функций компилируется для 1.21.11. Ввод возвращён на InputConstants с Window, интерфейс — на GuiGraphics, геометрия — на WorldRenderEvents и штатные буферы рендеринга.
- Gradle test сообщает NO-SOURCE; указанные изолированные проверки выполнялись отдельно.
- Фактически не проверены: эффекты на движущихся игроках, смерть игрока, работа проекции HUD при разных FOV, клики/перетаскивание в игровом меню, применение/восстановление оптимизации, реальное воспроизведение SoundCloud, совместимость с Sodium. Запуск клиента и сборка не заменяют эти проверки; прирост FPS не измерялся.
