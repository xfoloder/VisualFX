# Проверка VisualFX 1.13.0 — Minecraft 26.3

Изменения выполнены в проекте VisualFX-26.3. Проект VisualFX-1.21.11 не обновлялся.
Добавлены поля menuScale / menuX / menuY, перетаскивание верхней панели, ползунок 65–150%, центрирование и ограничение окна экраном. Отрисовка использует преобразование масштаба, а координаты мыши переводятся обратно в локальные координаты. Подсказки выводятся после снятия преобразования, в исходных координатах экрана. Масштаб применяется после завершения перетаскивания ползунка.
Gradle build выполнен успешно на JDK 25, Gradle 9.6.0, Loom 1.17.21. Minecraft 26.3, Loader 0.20.1, Fabric API 0.166.2+26.3.
Автоматические игровые тесты не выполнялись (test NO-SOURCE). Для 1.13.0 загрузка клиента, клики при разных масштабах, перетаскивание и изменение размера окна через игровой интерфейс фактически не проверены.
