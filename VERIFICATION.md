# VisualFX — проверки на Minecraft 1.21.11

## 1.19.7

В обоих клиентах Fabric проверены выбор цвета в квадрате и перетаскивание указателя, полосы оттенка и яркости, синхронизация HEX, раздельное редактирование двух цветов градиента и сохранение конфигурации. Проверен снимок палитры из клиента.

## 1.19.6

В одиночном мире Fabric проверены три независимых переключателя Watermark, все восемь сочетаний, сохранение настроек, значения по умолчанию для старых конфигураций и высота панели в каждом состоянии.

## 1.19.5

Gradle собрал установочный JAR. В локальном мире Fabric проверены выбор пресета во вкладке меню, предпросмотр пользовательского оттенка, сохранение темы и независимость палитры Watermark. Проверены координаты игрока с отрицательными значениями, форматирование координат у границы мира и высота Watermark с новой строкой.

## 1.19.4

Gradle собрал установочный JAR. В одиночном мире Fabric автоматическая проверка подала событие урона от локального игрока тестовой модели. Проверены выбранный цвет и отключение красного оверлея, затухание, возврат обычного цвета, урон из другого источника и выключенный Color Hit. Проверены выбор зелёного оттенка на цветовой полосе и открытие и закрытие меню из перемещённого Watermark. Проверка использовала тестовые события в клиенте.

## 1.19.3

Сборка Gradle прошла. В изолированном клиенте проверены добавление Cynthia-metaphor в пустой список, плашка при открытии списка, отсутствие повторной плашки за запуск, распознавание адреса с другим регистром и портом 25565, сохранность других записей и возможность удалить добавленный сервер.

## 1.19.2

Сборка на Java 21 прошла. В локальном клиенте Fabric тест воспроизвёл события входа, выхода и повторного входа для тестового подключения. Первый вход и повторный вход вызвали реальные HTTP-запросы к локальному ретранслятору и перевели статус в «В комнате» без открытия меню. Событие выхода очистило состояние комнаты.

## 1.19.1

Gradle собрал и переназначил установочный JAR на Java 21. В клиенте Fabric 1.21.11 загружен одиночный мир. Проверены рендер выпавшего предмета, снежинки и листья, открытие инвентаря и новых вкладок, окно комнаты и отображение зелёной кошки с тестовым статусом. Сетевой код этой сборки отправил два тестовых статуса через существующий ретранслятор и получил статус второго участника.

Реальный многопользовательский запуск на двух компьютерах и перенос стопки при физически зажатом Shift в эту проверку не входили.

## 1.19.0

Сборка для Fabric прошла. В запущенном клиенте на Java 21 нативная библиотека загрузилась. Совпали число, порядок, координаты и цвета вершин в 416 случаях Target ESP и отдельной серии из 1200 линий, которая пересекает границу пакета.

В изолированном замере расчёта эффекта «Энергоклетка» медиана составила 137,4 мкс на Java и 143,8 мкс на Rust. Замер включает передачу данных между Java и Rust. Рендеринг мира и FPS в замер не входили. На другом компьютере результат может отличаться. Java оставлена режимом по умолчанию.
