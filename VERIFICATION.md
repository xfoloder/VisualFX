# Проверка VisualFX 1.5.0 — Minecraft 26.3

Проект собирается Gradle 9.6.0 на JDK 25 с Loom 1.17.21.
Добавлены DeathEffectSystem, два режима смерти, ограниченные слоты эффектов, новые поля конфигурации, переключатели и прокрутка настроек Visual.
Детектор проверяет isDeadOrDying у последней цели; простое удаление сущности не считается смертью. Переключение мира и отключение функции очищают состояние. Окончание эффекта наступает по возрасту в клиентских тиках.
Автоматических игровых тестов нет (test NO-SOURCE). Для версии 1.5.0 фактическая проверка смерти игрока, визуального вида эффектов, меню и Sodium не выполнялась. Результат сборки находится в build-1.5.0.log рядом с JAR.
