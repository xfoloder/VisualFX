# Проверка версии для Minecraft 26.3

17 ноября 2026: сборка Gradle 9.6.0 с JDK 25 выполнена успешно.
Зависимости: Minecraft 26.3, Fabric Loader 0.20.1, Fabric API 0.166.2+26.3, Loom 1.17.21. Yarn не используется: игра предоставляет официальные имена классов.
Код перенесён на SDL через InputConstants, GuiGraphicsExtractor и очередь submitCustomGeometry / события LevelRenderEvents.
Запуск runClient: загрузчик обнаружил VisualFX 1.1.0+26.3; клиент инициализировал SDL и графический backend OpenGL и загрузил ресурсы мода.
Автоматические игровые тесты не выполнялись (test NO-SOURCE). Меню и эффекты на втором игроке визуально не проверены. Sodium не проверен.
Свечение реализовано геометрическими оболочками без bloom; Hit Effect реагирует на локальную попытку атаки.
