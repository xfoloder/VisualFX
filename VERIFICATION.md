# Проверка VisualFX 1.4.0 — Minecraft 26.3

Сборка Gradle build успешна на JDK 25, Gradle 9.6.0 и Loom 1.17.21.
Все семь реализаций эффектов скомпилированы против Minecraft 26.3 / Fabric API 0.166.2+26.3.
Выбор режима и чтение конфигурации используют фактическое число реализаций; имена режимов едины для меню и предпросмотра. Первые четыре индекса конфигурации сохранены.
Число элементов ограничено: энергоклетка — шесть меридианов по 48 сегментов и два кольца; корона — 12 зубцов и до 48 осколков; вихрь — до 48 осколков с шестью сегментами следа и одним кольцом.
Автоматических игровых тестов нет (test NO-SOURCE). Версия 1.4.0 в игре не запускалась. Внешний вид новых эффектов и совместимость с Sodium фактически не проверены.
